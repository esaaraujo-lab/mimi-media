## Nota técnica / Technical note

**Português:** Os ficheiros são enviados pela API do GitHub (Contents API) e servidos em `https://cdn.jsdelivr.net/gh/esaaraujo-lab/mimi-media@main/<caminho>`.

- `upload_images/` — fotos dos produtos.
- `products/<id>/` — fotos e vídeos novos enviados pelo admin da loja.
- `products/pending/` — fotos de produtos novos (antes de terem id).
- `avatars/` — avatares dos avaliadores (SVG).
- `hero/` — imagens e vídeos do hero da página inicial.

Nunca apagar os originais do `gdi_server` sem confirmar.

**English:** Files are uploaded via the GitHub API (Contents API) and served at `https://cdn.jsdelivr.net/gh/esaaraujo-lab/mimi-media@main/<path>`.

- `upload_images/` — product photos.
- `products/<id>/` — new photos and videos uploaded by the shop admin.
- `products/pending/` — photos of new products (before they have an id).
- `avatars/` — reviewer avatars (SVG).
- `hero/` — homepage hero images and videos.

Never delete the originals from `gdi_server` without confirming.
